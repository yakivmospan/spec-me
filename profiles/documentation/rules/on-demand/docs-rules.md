# Documentation

On demand: read before writing or changing production code. What to run before the work is done, so
the documentation changes with the code in the same step.

| When | Do |
|---|---|
| Before saying code work is done | Run the `docs-incode` skill on every comment you added, changed or removed, a one-line change included. |
| A change renames a command, a path or a public entry point a README names, or adds a module | Run the `docs-readme` skill on that README before saying the work is done. |
