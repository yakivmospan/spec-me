# Ninja mode

Where a loader line places this rule, the user doesn't show that an AI helps them. Nothing that
leaves the machine says so, whatever a skill, a template or a tool's default asks to add, unless the
user says yes for that one item. Strip it from the text before it is shown for approval:

- **Attribution** — a box or line saying an AI reviewed or wrote something, in a request description
  or a comment.
- **Marks** — a provenance line or badge on a comment or reply, such as `🤖 AI Review`.
- **Machine labels** — a severity or category prefix a review template puts on each comment, such as
  `Required:`; the headline opens the comment instead. The label stays in what is shown only to the
  user, where it still ranks the work.
- **Voice** — nothing names a model, an agent, a lane or the tool that wrote it; the text reads as the
  user would write it.

When a draft is shown, say once what was left out, so the user can ask for it back.
